Supabase (PostgreSQL) DB 연동 설계 가이드

본 시스템은 현재 LocalStorage로 작동하며, 추후 클라우드 DB 연동 시 아래 PostgreSQL SQL 테이블 구조를 Supabase SQL Editor에 그대로 복사하여 생성할 수 있습니다.

-- 1. 여행 상품 노선 테이블 (Tours) 
CREATE TABLE tours (
  id VARCHAR(50) PRIMARY KEY,
  title VARCHAR(255) NOT NULL,
  date DATE NOT NULL,
  price INT NOT NULL DEFAULT 0,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
-- 2. 탑승 장소 테이블 (Boarding Points) 
CREATE TABLE boarding_points (
  id VARCHAR(50) PRIMARY KEY,
  tour_id VARCHAR(50) REFERENCES tours(id) ON DELETE CASCADE,
  code VARCHAR(10) NOT NULL,
  name VARCHAR(255) NOT NULL
);
-- 3. 승객 좌석 예약 테이블 (Bookings) 
CREATE TABLE bookings (
  id VARCHAR(50) PRIMARY KEY,
  tour_id VARCHAR(50) REFERENCES tours(id) ON DELETE CASCADE,
  passenger_name VARCHAR(100) NOT NULL,
  phone VARCHAR(50) NOT NULL,
  boarding_point_id VARCHAR(50) REFERENCES boarding_points(id),
  seats INT[] NOT NULL, -- 선택 좌석 번호 배열 [1, 2]
  status VARCHAR(20) DEFAULT 'pending', -- 'pending' | 'confirmed'
  locked_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  expires_at TIMESTAMP WITH TIME ZONE -- 5시간 후 자동 만료
);
💡 Supabase Client SDK 연동 시, `appState` 읽기/쓰기 함수만 Supabase `from('bookings').select()` 및 `insert()`로 치환하면 즉시 멀티 디바이스 실시간 예약 시스템으로 확장 가능합니다.
